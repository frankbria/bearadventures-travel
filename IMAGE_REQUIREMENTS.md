## Image Specifications Summary

### File Format

- **Preferred:** JPG for photos, PNG for logos
- **Quality:** High quality, optimized for web
- **Compression:** Balance quality and file size (aim for <500KB per image)

### Dimensions by Type

- **Hero Images:** 1920x1080 minimum (3840x2160 for retina)
- **Blog Featured:** 1200x675 minimum (16:9 aspect)
- **Trip Cards:** 800x600 minimum (4:3 aspect)
- **Team Photos:** 400x400 (avatars), 600x800 (portraits)
- **Testimonials:** 300x300 minimum (square)
- **OG Image:** 1200x630 (1.91:1 aspect)

### Optimization Guidelines

1. Use WebP format when possible (Next.js will auto-convert)
2. Compress images before uploading
3. Use descriptive filenames with keywords
4. Ensure proper alt text in code
5. Consider lazy loading for below-fold images
